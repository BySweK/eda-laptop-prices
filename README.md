# Exploratory Data Analysis – Laptop Prices

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a laptop prices dataset.  
The main goal is to understand how different hardware features affect laptop prices and to extract meaningful insights that can support future machine learning models.

## Objectives
- Analyze the impact of CPU, RAM, memory, and other hardware features on laptop prices
- Understand the structure and distribution of the dataset
- Identify patterns, trends, and relationships between features
- Prepare a solid foundation for regression-based price prediction models

## Dataset
- Laptop prices dataset obtained from Kaggle
- Includes hardware and pricing information for various laptop models

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Steps
1. Data Understanding  
   - Overview of the dataset  
   - Feature types and distributions  

2. Data Cleaning and Preparation  
   - Handling missing values  
   - Data type conversions and feature extraction  

3. Exploratory Data Analysis  
   - Univariate and multivariate analysis  
   - Visualization of feature–price relationships  

4. Correlation Analysis  
   - Investigation of relationships between numerical features and price  

5. Insights and Interpretation  
   - Interpretation of visual and statistical findings  

## Key Insights
- CPU, RAM, and memory have a significant impact on laptop prices  
- Higher hardware specifications generally correlate with higher prices  
- Some features show wide price variation, indicating the influence of brand and configuration  

## Future Work
- Apply multiple linear regression for price prediction  
- Perform feature engineering based on EDA findings  
- Extend the analysis with classification or advanced regression models
